Link bezpośredni do projektu: https://projekt-dashboard.surge.sh/

Oto projekt typu Dashboard wykonany w języku React,zawiera on:

- LocalStroage, który zachowuje wpisane wartości po odświeżeniu strony,
- Możliwość usunięcia problemu gdy użytkownik zaznaczy iż został rozwiązany,
- Formularz do zgłoszenia problemu wraz z wyborem odpowiedniej opcji z select,
- Architektura oparta na react-router
